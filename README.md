# IT4403 - Adv Web and Mobile Application
This is the repo for my GitHub Pages hosted site to showcase course work for
IT4403.

Live site is [here](https://bigcheeze45.github.io/it4403/).

## Running Locally

I recommend using [Docker](https://www.docker.com/products/docker-desktop/) if you're interested in messing around with the repository.

1. Install docker
2. Download/clone the repo
3. In your terminal, from the project root: `docker compose up -d`
4. Point your browser to [http://localhost:4000/](http://localhost:4000/)
